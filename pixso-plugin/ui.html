常见问题
  1. 端口填的是本地桥的 WebSocket 端口（默认 3679），不是 MCP 的 HTTP 端口 3678。
  2. 连接成功后端口会被记住，下次打开面板自动填好；改动端口后重新连接即可覆盖记忆值。
  3. 提示令牌被拒绝时，填写与服务端 --token 完全相同的值后重新连接。
  4. 连接断开后本窗口会每 1.5 秒自动重试，不需要手动点连接。
  5. 改过插件代码后，需要关掉插件窗口再重新运行一次，Pixso 才会加载新的 main.js。
